知途课堂数据库表结构说明

本说明依据用户提供的 ER 图及当前 MySQL 数据库 zhitu_classroom 的实际元数据整理，供数据库设计报告与课程展示使用。当前包含 17 张基础表、1 个视图。字段类型、空值、默认值、主外键、索引和删除规则以实际 MySQL 为准；字段业务含义结合当前后端实现说明。

MySQL 版本：8.0.30。元数据采集时间：2026-10-14T10:52:05.133Z（UTC）。所有业务表使用 InnoDB；现有表排序规则包含 utf8mb4_unicode_ci 和 utf8mb4_0900_ai_ci，具体以建表定义为准；users.session_token_hash 单列使用 ascii_bin。本文仅导出结构，不包含用户记录、密码摘要值或登录令牌值。

三 字段结构

类型中的 UNSIGNED 表示无符号整数；VARCHAR(n) 中 n 为最大字符数，DATETIME(3) 表示毫秒精度。PK 为主键，FK 为外键，联合主键需组合唯一。允许空为“否”的字段具有 NOT NULL 约束；无默认值不等于默认 NULL。业务说明中的 0–100、字符数限制等来自接口，不能视为已建 CHECK 约束。

表 1 用户表 users

保存用户身份、密码摘要、头像、停用状态及唯一有效会话摘要和过期时间。

字段名数据类型允许空键与约束默认值字段说明
idBIGINT UNSIGNED否PK；自增— 无默认值用户编号
nicknameVARCHAR(100)否—— 无默认值登录昵称；唯一性以本次采集的实际索引为准
passwordVARCHAR(255)否—— 无默认值scrypt 密码摘要，不存储明文密码
avatarVARCHAR(255)是—NULL头像标识或资源值，可空
followingINT UNSIGNED否—0旧版关注数量字段；当前关注列表从 follows 查询
created_atDATETIME(3)是—CURRENT_TIMESTAMP(3)创建时间
disabledBIGINT否—0账号停用状态，0 正常，1 停用；停用撤销当前会话
session_token_hashCHAR(64)是—NULL当前单会话令牌的 SHA-256 摘要，可空，单列唯一，非明文令牌
session_expiresBIGINT是—NULL当前会话过期时间，Unix 毫秒，可空

索引：PRIMARY（主键；id）；uq_users_nickname（唯一索引；nickname）；uq_users_session_token_hash（唯一索引；session_token_hash）。

当前库的 nickname 具有单列 UNIQUE 约束；注册前检查与数据库唯一约束共同处理同名注册。

表 2 历史清除标记表 history_resets

每账号保存最近清除时间，防止旧播放进度补回访问历史；不删除播放进度。

字段名数据类型允许空键与约束默认值字段说明
user_idBIGINT UNSIGNED否PK— 无默认值用户编号，主键；逻辑关联 users.id
cleared_atDATETIME(3)否—CURRENT_TIMESTAMP(3)最近确认清除历史的服务端时间，UTC

索引：PRIMARY（主键；user_id）。

表 3 每日学习打卡表 study_checkins

记录用户按北京时间主动打卡的日期，每账号每天唯一，不代表观看时长。

字段名数据类型允许空键与约束默认值字段说明

checkin_dateDATE否联合 PK— 无默认值打卡业务日期，由服务器按 Asia/Shanghai 确定，客户端不能补签
created_atDATETIME(3)否—CURRENT_TIMESTAMP(3)服务端写入时间，UTC

索引：PRIMARY（主键；user_id、checkin_date）。

表 4 课程表 courses

保存课程目录及上架信息；分类和学科分别使用 category、subject。

字段名数据类型允许空键与约束默认值字段说明
idBIGINT UNSIGNED否PK；自增— 无默认值课程编号
titleVARCHAR(500)否—— 无默认值课程名称
categoryVARCHAR(255)否—— 无默认值学习方向，例如高中课程、考研课程
teacherVARCHAR(100)否—— 无默认值讲师姓名
descriptionTEXT否—— 无默认值课程简介及原站资源说明
coverVARCHAR(255)否—— 无默认值封面标签文字；课程图片按课程 ID 读取静态资源
accentVARCHAR(255)否—— 无默认值课程配色标识
lessonsSMALLINT UNSIGNED否—— 无默认值课程分集数量
studentsINT UNSIGNED否—0历史学习人数展示字段，并非实时学习记录计数
durationVARCHAR(255)否—— 无默认值课程总时长展示文本
levelVARCHAR(255)是—'入门'课程难度或学习阶段

created_atDATETIME否—CURRENT_TIMESTAMP创建时间
publishedBIGINT否—1当前课程上架标记，1 为上架、0 为下架
subjectVARCHAR(255)否—'' 空字符串具体学科，例如数学、Python

索引：idx_course_category_students（普通索引；category、students）；idx_course_teacher（普通索引；teacher）；PRIMARY（主键；id）。

status 是旧字段，published 才是当前后端筛选上架课程的依据；二者并未通过数据库约束自动同步。
