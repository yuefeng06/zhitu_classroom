# 后台内容维护（更新至 2026-10-31）

入口：管理员登录后进入 `#/admin`，或从个人中心进入管理工作台。普通注册不能自行取得管理员身份。

## 前后台对应关系

| 前台功能 | 后台维护 | 删除规则 |
| --- | --- | --- |
| 课程列表、搜索、首页推荐 | 新建、查询、编辑课程，上架/下架，上传封面 | 先下架；无章节和学习互动记录时可删除 |
| 分集目录和视频播放 | 新增、查询、编辑、排序、删除章节；上传视频或配置 Bilibili / HTTP(S) 片源 | 先下架课程；有收藏、笔记、评论、进度、访问或弹幕关联的章节禁止删除 |
| 发现页学习文章、全文阅读 | 新增、查询、编辑、发布/撤回、删除文章 | 版本确认后删除；草稿不公开 |
| 登录与账号信息 | 新建普通账号、查询、修改昵称、停用/启用 | 仅删除无学习或互动记录的已停用普通账号；管理员受保护 |
| 章节讨论 | 按课程、章节、内容及状态查询，保留/恢复、隐藏、删除 | 显示作者和课程章节，可直达视频；版本确认后删除，不改写发言正文 |

收藏、私有笔记、访问历史和打卡由用户操作产生，管理看板显示真实汇总，不给管理员伪造学习记录或阅读他人私有笔记的入口。分类仍使用现有四类，不包含分类字典管理。直播不恢复。

## 用户详情与头像维护

进入 **用户管理 → 用户详情**，可查看头像、用户编号、注册日期、状态，以及笔记、章节收藏、关注讲师、最近访问课程、累计打卡天数和讨论数量。统计读取真实记录，包含已下架内容的保留关联；访问数不是播放次数，累计打卡不等于观看时长，也不等同于用户端近 365 天的打卡窗口。

关注讲师列表按姓名分页（每页 20 条），显示各讲师当前已上架课程数。关注由用户产生，后台可在学习记录管理中移除指定关注；不代替用户制造关注或学习记录。笔记库只显示数量，接口不返回私人笔记正文。昵称和账号状态仍通过“编辑资料”维护，删除仍受学习关联保护。

普通账号的详情顶部提供 **更换头像** 快捷入口。支持选择最大 4 MB 的 JPG、PNG、WebP，浏览器居中裁剪成 256×256 JPEG；预览后点击“保存头像”并确认目标账号。也可确认恢复默认头像。管理员自己的头像在个人中心修改，后台不能修改其他管理员头像。前台下次读取资料时显示更新后的头像，已打开的页面可刷新查看。

新增 `GET /api/admin/users/:id/detail?page=1` 和 `POST /api/admin/users/:id/avatar`。头像写入要求管理员会话、目标昵称确认与用户资料版本一致，事务中再次检查权限目标和版本；普通账号和匿名访问会被拒绝。复用 `users.avatar` 和私有 `AVATAR_DIR`，不新增表、不迁移数据库；旧头像文件保留，不自动清理。

后端修改后需要重启网站服务。隔离接口和 MySQL 回归覆盖身份、版本冲突、无效图片、前台头像读取、恢复默认与笔记隐私；`ADMIN_ONLY=1` 的浏览器回归覆盖详情、预览、确认取消和手机布局。

## 演示“上传自己的视频”

1. **课程管理 → 新建课程**：填写名称、讲师、分类、学科、简介等，保存为草稿。编辑窗口顶部的 **保存并添加章节 / 上传视频** 可直接进入章节管理；已有课程使用 **保存并管理章节 / 上传视频**，会先保存当前修改。
2. **更换封面**：选择 JPEG / PNG，最大 2 MB，建议 16:9。未上传时使用对应分类的本地主题图片。
3. **章节 / 上传视频 → 新增章节并上传视频**：填写标题、时长和序号，点击 **保存并上传视频**，直接进入上传界面；章节数量自动更新。
4. 已有章节点击 **上传 / 更换视频**；选择本地 MP4 / WebM，再点 **上传并绑定本章节**。完成后已保存，无需再填 B 站参数。也可在同一入口更换视频。
5. 返回课程编辑，将状态改为 **已发布**。没有章节的课程不能发布；没有配置片源的章节明确显示尚未发布，不播放演示素材。
6. 返回用户端，在课程列表或搜索中找到新课程，点击对应章节播放。原生视频支持进度条、跳转和本站章节进度记录。

MP4 推荐 H.264/AAC 编码，WebM 使用浏览器支持的编码。服务端校验类型、签名和大小，不提供转码、断点续传或病毒扫描；扩展名正确不保证浏览器支持内部编码。默认单视频上限 512 MB，可用 `VIDEO_MAX_MB` 调整。自动获取片源时长和 B 站分集暂不提供，标题、时长、序号由管理员维护。

## 按章节视频审核评论

进入 **讨论审核**，先选课程，再选具体章节。每条评论显示作者、创建时间、所属课程、章节及可见状态；“查看对应视频”直达该集。“已保留”表示当前可见，“隐藏”暂时从前台移除，“保留并恢复显示”恢复可见；“删除”需确认并核对行版本。审核操作完成后，前台下一次读取或切回该章节即显示最新结果，当前页面不做实时推送。

前台发布必须提交当前 `chapterId`，服务端验证章节归属。切换视频会加载本节评论并保留各节未提交草稿，过期请求不能覆盖新章节。下架课程不接受新评论。有评论关联的章节不能直接删除。

2026-10-31 增量新增 `comments.chapter_id`（可空，类型与 `chapters.id` 一致）及索引 `(course_id,chapter_id,hidden,id)`，不新增物理外键。旧评论没有章节信息，保持 `NULL`，通过“历史课程评论（未绑定章节）”筛选维护，不凭猜测挂到第一集。

旧库升级先运行 `node scripts/add-chapter-comments.mjs` 只读预检，停止网站写入后运行 `node scripts/add-chapter-comments.mjs --apply --maintenance`。脚本将原表结构和评论备份到私有 `database/backups/chapter-comments-…/`，仅添加列与索引，不改写评论正文、时间或审核状态。DDL 会隐式提交，备份不能公开。升级后重启网站即可，不运行全量迁移、不重启 MySQL。

## 存储、备份与权限

- 课程、章节、账户、评论和文章写入 MySQL。新增封面复用 `courses.cover`，不新增业务表或物理外键。
- 播放映射保存在 `MEDIA_CONFIG_PATH`，默认 `media-sources.json`；视频文件存放 `VIDEO_DIR`，默认 `data/videos/`。上传后绑定到实际章节，前台通过受控 `/api/videos/…` 接口读取，支持 Range 和 HEAD。
- 封面文件存放 `COURSE_COVER_DIR`，默认 `data/course-covers/`，通过 `/api/course-covers/…` 读取。不能直接列出或下载目录。未发布课程的本地视频和封面只允许管理员预览。
- 替换视频/封面后旧 URL 失效；删除章节/课程后对应 URL 失效。旧文件和片源备份暂留作恢复资料，不自动删除，清理前需核对当前绑定和备份。不是对象存储或自动垃圾回收系统。
- 片源保存前备份到配置目录下 `data/media-backups/`，随后原子替换并即时更新内存。单服务进程内串行写入并校验版本；不支持多个服务进程同时修改同一配置。
- 数据库和文件系统无法组成同一个数据库事务。正常失败会清理本次上传；进程突然退出仍可能留下未绑定文件或 `.part`。备份须一起保存数据库、片源配置、视频、封面和头像目录。
- 2026-10-30 已执行 `node scripts/import-editorial-articles.mjs --apply`，将 9 篇原有学习经验和《提问的智慧》导入业务 MySQL 的 `admin_articles`。执行前备份原文章表到私有 `data/article-backups/`，再次预检显示待导入 0 篇。发现页现在只展示数据库已发布文章，后台修改会影响实际阅读内容。
- 原始精选和 Markdown 文件继续作为出处与导入源保存，不作为发现页运行数据。导入脚本是一次性初始化工具，删除文章后不要再次运行 `--apply`，否则缺失的原文会被重新导入。
- 文章支持安全的 Markdown 子集排版、目录内跳转和来源链接，原始 HTML 转义。保留原作者、译者和短摘录信息。
- 用户端写入和后台删除共同锁定所属课程，检查逻辑关联，不能依赖已经移除的物理外键。编辑和删除均检查行版本，避免覆盖旧页面上的数据。

## 学习记录管理与弹幕管理（2026-10-31）

后台新增“学习记录管理”和“弹幕管理”。用户详情的入口自动带上该用户编号。学习记录按类型每页 30 条，支持昵称/用户编号、适用的课程/章节与北京时间日期查询，保留下架内容的关联记录。

| 类型 | 查询内容 | 维护边界 |
| --- | --- | --- |
| 历史记录 | 用户、课程、最近章节和访问时间 | 确认后清理单条，不删除收藏/笔记/进度；写 history_resets，停止从旧 progress 补回历史 |
| 章节收藏 | 用户、具体视频、收藏时间、上架状态 | 确认移除后，前台书架下一次读取同步变化 |
| 每日打卡 | 用户、日期、创建时间；精确用户月份日历 | 只清理真实记录，不新增或补签；31 天跨页完整显示 |
| 播放进度 | 章节、当前位置、视频时长、百分比 | 只读；不是实际观看时长，表中未记录更新时间 |
| 笔记元信息 | 编号、用户、课程章节、时间点、创建时间 | 不返回正文，不提供修改或删除入口 |
| 关注讲师 | 用户和讲师名称 | 可确认移除；原表没有关注时间，不编造日期 |
| 弹幕 | 内容、作者、课程章节、视频秒数、可见状态 | 可隐藏、恢复和确认删除，不代写或改写正文 |

查询使用参数绑定。清理和审核在服务端校验管理员权限、行版本并在事务中执行；界面过期时返回 409，避免误删已更新记录。历史列表主要查询 course_visits；旧 progress 兼容回填不是新的访问事件。无批量清空或为用户制造记录的接口。

弹幕审核对应 GET /api/admin/danmaku、PATCH/DELETE /api/admin/danmaku/:id；学习记录对应 GET /api/admin/learning/:kind，kind 为 history、favorites、checkins、playback、notes、follows。只有 history、favorites、checkins、follows 支持 DELETE，正文传 key、version、confirm（目标用户编号）。前台弹幕必须绑定章节，由当前会话写入作者；隐藏结果在重新读取/切换章节时生效，尚无实时推送。

普通账号可通过“用户管理 → 用户详情 → 重置登录密码”维护。要求两次输入 8–128 位密码、确认目标账号；服务端重新检查目标角色与版本，更新密码摘要并撤销旧会话。管理员账号受保护，不能通过该入口重置；密码不会回传或写入日志。

业务 MySQL 已备份并执行 scripts/add-danmaku-moderation.mjs --apply --maintenance，新增 danmaku.user_id、hidden 及查询索引，原 3 条弹幕保留，未知作者继续为空。其他旧环境先运行不带参数的预检，停止写入后升级。私有备份在 database/backups/danmaku-…/，DDL 不可事务回滚。没有新增物理外键，不运行全量迁移。

分类仍沿用既有四类；讲师仍为文本字段，独立字典和统一更名迁移属于后续功能。账户已具备本轮普通账号密码重置，未实现邮箱找回流程。部署仍需启动新版 Node 服务；此前后台启动命令被环境审批拒绝，本轮不把隔离测试通过当作业务服务已运行。
