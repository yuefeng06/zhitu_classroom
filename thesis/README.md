# 知途课堂毕业设计论文初稿

题目：基于 Node.js 与 MySQL 的在线学习平台设计与实现——以“知途课堂”为例。

修订日期：2026-10-08（测试与实验执行于10月7日）。学校暂无指定模板；封面和致谢个人信息留空，当前仍为待作者定稿的初稿。

## 文件

- 毕业论文初稿.md：中英文摘要、八章正文、十条参考文献及附录。
- 毕业论文初稿.tex：由 generate-latex.mjs 从Markdown转换的ctexbook源稿，含三张TikZ图；手工精修TeX后不要继续自动覆盖。
- zhitu-classroom-source.zip：附录A链接的源码快照，含README-SOURCE和SHA-256清单，排除账户、头像、密码配置、业务库及私有模型。
- evidence/platform-validation.md：本轮验证及边界；summary-benchmark.json与recommendation-synthetic.json为实验原始汇总。
- evidence/environment.json：环境与分层验证范围。旧验证文件按原日期保留，不代表最新全部结果。

## 当前结果

接口及算法24项通过；独立MySQL13项通过；Edge管理端专项1项通过，包含桌面、手机、文章发布阅读和文本转义。全量浏览器回归本轮未重跑。业务MySQL结构为22表、102字段、30外键、1视图，目录33门上架课程与2,205个分集。

后台已具备真实授权、课程/文章/讨论管理、用户状态和事务审计；昵称具有唯一索引，密码派生异步有界；课程摘要改为4次批量查询。第七章的时间对比仅为单连接临时表函数基准，推荐效果仅为合成样本对照。业务训练数据不足，机器学习未启用，不能宣称提升学习效果或生产性能。

## 排版与定稿限制

本轮更新并静态检查TeX源文件，没有生成新版PDF。当前会话未提供内置LaTeX编辑/编译工具；此前Tectonic依赖下载因TLS错误失败且缓存不完整，没有安装新工具链。可用完整XeLaTeX环境后在本目录连续运行两次 xelatex -interaction=nonstopmode -halt-on-error 毕业论文初稿.tex，再检查中文字体、目录、表格、分页和溢出。

论文新增技术描述与源码、实际结构、实验记录对齐，但定稿仍需扩展中文文献、补充学校格式、全量浏览器回归及真实用户评价。参考文献保留来源链接，没有虚构用户调研、成绩、线上规模或个人贡献。
