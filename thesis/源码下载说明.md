# 知途课堂源码附件

版本日期：2026-10-08。对应《基于 Node.js 与 MySQL 的在线学习平台设计与实现》初稿。

解压后进入 `zhitu-classroom` 文件夹。本包是源代码与公开页面资源快照，不是业务数据库备份；不附 `.env`、账户记录、上传头像或私人笔记。文件清单及 SHA-256 保存在 `SOURCE-MANIFEST.json`。

## 在独立环境快速演示

需要 Node.js 22.13 或更新版本。以下命令请在解压出的独立目录运行，显式创建 SQLite 演示数据库；不会访问原项目 MySQL 业务库。

```powershell
npm install
$env:DB_CLIENT='sqlite'
$env:DB_PATH=Join-Path (Get-Location) 'demo.sqlite'
$env:AVATAR_DIR=Join-Path (Get-Location) 'demo-avatars'
$env:PORT='3001'
npm start
```

打开 `http://localhost:3001`，可以注册新的演示账号。服务按初始化代码创建演示记录，来源是代码中的公开课程快照，不是作者的业务账户。原站视频仍需网络且受原站可用性限制。默认头像文件若不存在，服务器会使用品牌图标。

这条 SQLite 路径仅用于明确选择的演示与隔离验证，论文中的实际业务数据库仍是 MySQL。

## 接入自己的 MySQL

新建专用空库，在该空库执行 `database/mysql-actual-schema.sql`（仅结构，不含数据）。不要在已有业务库重复执行。复制 `.env.example` 为本机 `.env`，填写自己的主机、用户、密码和目标库。

如刚才运行过 SQLite 演示，请先按 Ctrl+C 停止，并使用新的 PowerShell 窗口，避免之前的环境变量覆盖 `.env`。

在项目根目录获取本快照的课程编号，再预检并同步到专用空库：

```powershell
$courseIds = node --input-type=module -e "import {videoCatalog,retiredCourseIds} from './catalog.mjs';console.log(videoCatalog.filter(c=>!retiredCourseIds.includes(c.id)).map(c=>c.id).join(','))"
node scripts/sync-mysql-catalog.mjs "--ids=$courseIds"
node scripts/sync-mysql-catalog.mjs "--ids=$courseIds" --apply
npm run db:check
npm start
```

请阅读脚本的预检结果后再应用。此流程从公开课程元数据初始化专用库，不需要原作者的 SQLite 数据文件，也不执行历史用户迁移。普通启动不应执行 `npm run db:migrate`。

## 管理员与新增功能

注册自己的账号后，在正确数据库配置下执行 `node scripts/grant-admin.mjs --nickname=你的昵称` 预检，确认唯一匹配再加 `--apply`。这会授权该账号管理课程、文章、讨论及普通账号状态。发布的文章在发现页展示。附件不附作者的管理员账号数据。
